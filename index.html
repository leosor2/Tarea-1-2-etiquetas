img

La etiqueta <img> es una etiqueta de autocierre que permite insertar imágenes en la página web.

input

La etiqueta <input> es una etiqueta de autocierre que permite crear campos de entrada en formularios.





link

La etiqueta <link> es una etiqueta de autocierre que permite enlazar archivos externos, como hojas de estilo CSS.

meta

La etiqueta <meta> es una etiqueta de autocierre que permite especificar metadatos sobre el documento HTML.

col

La etiqueta <col> es una etiqueta de autocierre que permite definir columnas en una tabla.

embed

La etiqueta <embed> es una etiqueta de autocierre que permite insertar contenido externo en la página web.

param
